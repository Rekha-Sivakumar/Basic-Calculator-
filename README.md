# Basic Calculator (Tkinter)

A simple scientific calculator desktop app built with Python and Tkinter.  
Supports basic arithmetic, trigonometric functions, square root, constants (π, e), and more.

## Features

- Addition, subtraction, multiplication, division, modulus
- Trigonometric functions: sin, cos, tan
- Square root, parentheses, decimal point
- Constants: π (pi), e (Euler's number)
- Power operator (`^`)
- Clear and Backspace buttons
- Error handling for invalid input

## How to Run

1. Make sure you have Python 3 installed.
2. Save the code as `main.py`.
3. Open a terminal in the project folder.
4. Run:

   ```
   python main.py
   ```

The calculator window will appear.

## Requirements

- Python 3.x (no external libraries needed)
